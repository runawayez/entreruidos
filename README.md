# Entre Ruidos — site

Versão atualizada do site do podcast, pronta para Vercel.

## Nesta versão
- header sticky;
- navegação suave sem adicionar `#inicio`, `#episodios`, etc. à URL;
- offset correto ao navegar para seções abaixo do header;
- botões com ícones de Spotify, YouTube e RSS;
- player próprio com play/pause, progresso, tempo e volume;
- arte do episódio mais recente exibida inteira em formato quadrado;
- episódios do RSS em cards textuais, sem miniaturas;
- seção Sobre ampliada;
- seção Contato com e-mail clicável;
- fundo do hero unificado e mais integrado à identidade visual.

## Publicar
1. Substitua os arquivos do repositório pelos desta pasta.
2. Faça commit e push na branch de produção (normalmente `main`).
3. A Vercel faz o deploy automaticamente.
